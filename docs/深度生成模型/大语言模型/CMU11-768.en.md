# CMU 11-768: AI Agents

## Course Overview

- University: Carnegie Mellon University
- Prerequisites: Experience training neural language models; graduate NLP coursework such as CMU 11-667 or 11-711 is recommended; proficiency in Python
- Programming Language: Python
- Course Difficulty: 🌟🌟🌟🌟
- Estimated Study Hours: 70 hours

A graduate course from CMU's Language Technologies Institute, taught by Graham Neubig and Daniel Fried, on LLM-based AI agents, balancing current research with hands-on engineering. The course is organized into five parts:

1. **Agent capabilities**: tool use, context management, skills and memory, planning.
2. **Application domains and training**: coding, GUI, and research agents, plus supervised fine-tuning.
3. **Reinforcement learning**: RL fundamentals and advanced techniques for agents.
4. **Safety and frameworks**: safety, sandboxing, and agent frameworks such as OpenHands and LangGraph.
5. **Human-agent interaction and search**: interaction with people, search methods, and guest lectures.

Lecture recordings and slides are released on the course website as the semester progresses. Assignment 1 (building a ReAct-style agent harness) is fully open source and a great entry point for self-learners: you implement prompt construction, a tool-call loop with error recovery and step limits, tool execution in a Modal sandbox, skill discovery, and context compaction, then use your agent to fix a bug in a chess app, submit a SWE-bench Django patch, and play against a deterministic chess bot.

**Self-study tips**:

- Assignment 1 requires a Modal account and access to an OpenAI-compatible LLM API.
- Later assignments (agent evaluation, SFT and RL pipelines) and the sponsored compute are only available to enrolled CMU students; self-learners can instead build a small project on an open-source agent framework alongside the lectures.
