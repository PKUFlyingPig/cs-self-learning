# CMU 11-768: AI Agents

## 课程简介

- 所属大学：Carnegie Mellon University
- 先修要求：有训练神经语言模型的经验，建议先修 CMU 11-667 或 11-711 等研究生 NLP 课程；熟练掌握 Python
- 编程语言：Python
- 课程难度：🌟🌟🌟🌟
- 预计学时：70 小时

这是 CMU 语言技术研究所（LTI）由 Graham Neubig 和 Daniel Fried 讲授的研究生课程，系统介绍基于大语言模型的 AI Agent，内容兼顾前沿研究与工程实践。课程大致分为五个部分：

1. **Agent 核心能力**：工具调用、上下文管理、技能与记忆、规划。
2. **应用领域与训练**：代码 Agent、GUI Agent、研究型 Agent，以及监督微调（SFT）。
3. **强化学习**：面向 Agent 的强化学习基础与进阶技术。
4. **安全与框架**：安全性、沙箱隔离，以及 OpenHands、LangGraph 等 Agent 框架。
5. **人机交互与搜索**：人与 Agent 的交互、搜索方法，以及业界嘉宾讲座。

课程讲座视频和幻灯片随学期进度在课程网站公开。作业一（实现一个 ReAct 风格的 Agent harness）的代码与说明完全开源，非常适合自学者上手：你需要从零实现 prompt 构造、带错误恢复和步数限制的工具调用循环、在 Modal 沙箱中执行工具、技能发现和上下文压缩，再用自己写的 Agent 去修复一个国际象棋应用的 bug、为 SWE-bench 中的 Django 问题提交补丁，并与一个确定性的象棋机器人对弈。

**自学建议**：

- 作业一需要注册 Modal 账号，并准备一个兼容 OpenAI 接口的 LLM API。
- 后续作业（Agent 评测、SFT 与 RL 训练流水线）及课程提供的算力仅对 CMU 选课学生开放，自学者可以结合讲座内容，自己在开源 Agent 框架上做一个小项目作为替代。
