# CMU 10-799: Diffusion & Flow Matching

## 课程简介

- 所属大学／机构：Carnegie Mellon University
- 先修要求：Python 编程、微积分、线性代数、微分方程与概率基础，以及至少一门机器学习或深度学习课程
- 编程语言：Python (PyTorch)
- 课程难度：🌟🌟🌟🌟（主观参考）
- 预计学时：50–80 小时（含阅读与练习的自学估计，非官方统计）
- 课程版本：Spring 2026，7 周 Mini 3

Yutong (Kelly) He 主讲的生成模型专题课，将 Diffusion 与 Flow Matching 放在同一条学习主线上，从概率生成建模、DDPM 与 score-based SDE 一直讲到 Flow Matching、快速采样、可控生成、蒸馏、flow maps，以及离散 diffusion / flow matching。课程时间虽短，但主题集中，适合已有机器学习基础、希望系统进入现代 diffusion / flow 方法的读者。

这门课尤其适合自学的一点是作业资源非常完整：四次 homework 采用同一套代码逐步累积，前两次分别实现 DDPM 和 Flow Matching，后两次再从 fidelity、controllability 或 speed 中选择一个方向继续改进。官网公开了四份 Assignment PDF，HW1 提供公开 starter code；课程还明确说明校外学生可以公开访问录像、课件、作业、代码和其他资源。

## 自学建议

建议先完成 HW1 和 HW2，确保能独立实现 DDPM 与 Flow Matching，再选择一个 specialization path 做 HW3–HW4。后两次作业更接近小型研究项目，自学时最好固定计算预算和评估方式，先建立可靠 baseline，再比较自己的改动。如果 SDE / Flow Matching 的数学背景较弱，可以同时参考 [MIT 6.S184](MIT6.S184.md)。
