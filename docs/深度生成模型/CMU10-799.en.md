# CMU 10-799: Diffusion & Flow Matching

## Descriptions

- Offered by: Carnegie Mellon University
- Prerequisites: Python programming, calculus, linear algebra, differential equations, probability, and at least one machine learning or deep learning course
- Programming Languages: Python (PyTorch)
- Difficulty: 🌟🌟🌟🌟 (editorial estimate)
- Class Hour: 50–80 hours (editorial self-study estimate including reading and exercises)
- Course Version: Spring 2026, seven-week Mini 3

Taught by Yutong (Kelly) He, this focused course places diffusion and flow matching on one learning path, starting with probabilistic generative modeling, DDPM, and score-based SDEs, then moving to flow matching, fast sampling, controllable generation, distillation, flow maps, and discrete diffusion / flow matching. It is a compact advanced course for learners who already have a machine-learning background and want to study modern diffusion and flow methods systematically.

The public homework resources make it particularly suitable for self-study. Four cumulative assignments share the same codebase: HW1 implements DDPM, HW2 implements Flow Matching, and HW3–HW4 specialize in fidelity, controllability, or speed. The course website publishes the assignment PDFs and starter code, and the official self-study page explicitly states that lecture recordings, slides, homework, code, and resources are publicly available to students outside CMU.

## Self-Study Advice

Complete HW1 and HW2 first so that you can implement both DDPM and Flow Matching independently, then choose one specialization path for HW3–HW4. The later assignments are closer to small research projects, so establish a reliable baseline and keep compute and evaluation procedures fixed when comparing changes. If the SDE / Flow Matching mathematics is unfamiliar, [MIT 6.S184](MIT6.S184.md) is a useful companion.
