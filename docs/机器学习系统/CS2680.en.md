# Harvard CS2680: Modern AI Systems: Agents and System Optimizations

## Course Overview

- University: Harvard
- Semester: Fall 2026
- Prerequisites: CS61 or equivalent computer systems background, at least one graduate-level computer systems course, and familiarity with Python and PyTorch
- Programming Languages: Python and shell; other languages may be used depending on the implementation, and prior CUDA experience is not required
- Difficulty: 🌟🌟🌟🌟 (graduate-level systems course)
- Estimated Hours: Approximately 46–65 hours for the five assignments, based on the course's estimates, plus classes, paper reading, and the final project

Taught by Juncheng Yang, this course connects agent design with inference infrastructure through a progressively developed agent system. The first half covers coding agents, tools and context management, multi-agent coordination, memory, reliability, and evaluation. The second half examines LLM serving, including batching and scheduling, KV caches and prefix reuse, routing, quantization, and speculative decoding. Experiments track task success, cost, latency, and throughput. The course is suited to learners with a systems background who want to understand how agent applications and inference infrastructure can be optimized together.

The five individual assignments progress from building a web interface for Claude Code to implementing an agent loop, reducing model API cost and latency, serving an open-weight model for the agent, and profiling and optimizing the complete system. The final project offers product and research tracks, both requiring measurements to support a conclusion. There are no exams; the emphasis is on implementation, measurement, and analysis.

For self-study, note that lectures are not recorded. Public materials mainly consist of slides linked from the schedule, readings, and assignment specifications. As of October 15, 2026, detailed specifications for Assignments 1–3 are available, while Assignments 4–5 have overviews only; further materials are released as the semester progresses. Course-provided model APIs, Claude Code licenses, and GPUs are not available to auditors, so independent learners need to arrange their own resources. The systems half assumes substantial knowledge of operating systems, concurrency, networking, and performance analysis, even though the opening agent lectures are more introductory.
