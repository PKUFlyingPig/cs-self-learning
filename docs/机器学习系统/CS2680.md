# Harvard CS2680: Modern AI Systems: Agents and System Optimizations

## 课程简介

- 所属大学：Harvard
- 课程学期：Fall 2026
- 先修要求：CS61 或同等计算机系统基础，至少一门研究生级别的计算机系统课程，熟悉 Python 和 PyTorch
- 编程语言：Python、Shell；部分作业可根据实现选择其他语言，无需 CUDA 基础
- 课程难度：🌟🌟🌟🌟（研究生系统课程）
- 预计学时：五次作业合计约 46–65 小时（课程官方估计），另需安排课堂学习、论文阅读和期末项目的时间

这门由 Juncheng Yang 讲授的课程，以一个逐步完善的智能体系统为主线，将智能体设计与底层推理服务连接起来。前半部分介绍编程智能体的使用、工具与上下文管理、多智能体协作、记忆、可靠性和评测；后半部分转向大语言模型推理服务，覆盖批处理与调度、KV cache 与前缀复用、路由、量化和推测解码等优化方法。课程强调通过实验衡量任务成功率、成本、延迟和吞吐量，适合已有系统基础、希望理解智能体应用与推理基础设施如何共同优化的学习者。

五次个人作业依次要求搭建 Claude Code 的 Web 界面、实现自己的智能体运行循环、优化模型 API 调用的成本与延迟、部署开放权重模型并接入智能体，以及分析和优化整个系统。期末项目可选择解决实际问题的产品方向或研究方向，需要用实验数据支持结论。课程不设考试，学习重点是实现、测量和分析。

自学时需要注意：课程明确不提供课堂录像，主要公开材料是课表中的讲义、阅读资料和作业说明。截至 2026 年 10 月 15 日，作业 1–3 的详细说明已发布，作业 4–5 仅有概览，后续材料会随学期推进发布。课程提供给注册学生的模型 API、Claude Code 授权和 GPU 资源不向旁听者开放，自学者需要自行准备相应资源。后半部分对操作系统、并发、网络和性能分析基础的要求较高，不能只依靠开头的智能体入门内容判断难度。
