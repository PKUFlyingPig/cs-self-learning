# CS224R: Deep Reinforcement Learning

## Descriptions

- Offered by: Stanford
- Prerequisites: CS229 or equivalent machine learning knowledge, probability, linear algebra, multivariable calculus, and basic deep learning and reinforcement learning
- Programming Languages: Python (PyTorch)
- Difficulty: 🌟🌟🌟🌟
- Class Hour: About 10 weeks (Spring 2025 schedule; time spent on assignments and the project varies)

Taught by Chelsea Finn, CS224R explores learning decision-making policies with deep neural networks from interaction and existing data. Topics include imitation learning, policy gradients, actor-critic methods, Q-learning, offline RL, reward learning, model-based RL, multi-task RL, meta-RL, and hierarchical RL, with applications in robotics and large language models.

The course complements Stanford CS234, emphasizing deep learning and practical applications; CS234 is not a prerequisite. Learners should understand neural network training and Markov decision processes (MDPs), and be comfortable programming in Python.

The public videos below are from Spring 2025. Use that offering's slides and assignments alongside them, as the main website changes with each offering.
