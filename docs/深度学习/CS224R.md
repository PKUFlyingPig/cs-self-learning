# CS224R: Deep Reinforcement Learning

## 课程简介

- 所属大学：Stanford
- 先修要求：CS229 或同等机器学习基础，概率论、线性代数、多元微积分，深度学习与强化学习基础
- 编程语言：Python（PyTorch）
- 课程难度：🌟🌟🌟🌟
- 预计学时：约 10 周（按 2025 年春季课表，作业与项目用时因人而异）

CS224R 由 Chelsea Finn 教授主讲，介绍如何利用深度神经网络从交互经验和已有数据中学习决策策略。课程涵盖模仿学习、策略梯度、Actor-Critic、Q-learning、离线强化学习、奖励学习、基于模型的强化学习，以及多任务、元强化学习和分层强化学习等主题，并讨论机器人和大语言模型中的应用。

这门课与 Stanford CS234 相互补充，更侧重深度学习方法与实际应用，CS234 并非其先修课程。自学前应熟悉神经网络训练、马尔可夫决策过程（MDP）等基础概念，并具备使用 Python 完成编程作业的能力。
