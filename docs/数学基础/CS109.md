# Stanford CS109: Probability for Computer Scientists

## 课程简介

- 所属大学：Stanford
- 课程难度：🌟🌟
- 先修要求：高一数学足够了
- 编程语言：Python（稍微会一点就行，现在用ai也可以）
- outcome: nlp/ml/ai 必备前置课

如果你和我一样是文转码选手，或者也是在上Upenn 5920切头昏眼花，再或者想给自己补一补概率与统计基础，这节课就是量身为你打造的！

prof Chris Piech 是本人最喜欢的教授之一。他不但讲课超级无敌有激情，而且条例清晰，循循善诱。无论你是数学小白，还是理科达人，都可以在他的课堂里掌握基础的统计知识。堪称ai必备前置课~
课程从排列组合和概率的基本概念讲起，逐步介绍条件概率、贝叶斯定理、随机变量、常见分布、期望与方差，再进入参数估计和机器学习。后半部分会讲到最大似然估计、朴素贝叶斯和逻辑回归，把前面学过的数学与具体模型联系起来。如果你学机器学习时常常觉得“公式看过了，但不知道为什么这样算”，这门课很值得拿来补基础。

我也很喜欢它把概率论用起来的方式：分析 Bloom Filter，用概率模型处理按键识别和症状推断问题，再到自己实现机器学习算法。学过的概念会在具体问题里反复出现，让人更容易理解它们为什么有用。

配套的在线讲义也值得一起看，里面有公式、例子、代码和交互演示，适合边看视频边查阅。自学时建议把习题也做起来，尤其是条件概率和随机变量部分——听懂老师的讲解，到自己能列出式子，中间往往还需要一些练习

## 课程作业

1. [Counting](https://cs109psets.netlify.app/fall22/pset1/)：计数与排列组合。
2. [Core Probability](https://cs109psets.netlify.app/fall22/pset2/)：概率基础。
3. [Random Variables](https://cs109psets.netlify.app/fall22/pset3/)：随机变量，应用包括气候数据、算法艺术和 Bloom Filter。
4. [Probabilistic Models](https://cs109psets.netlify.app/fall22/pset4/)：概率建模，应用包括按键识别、症状推断和 Thompson Sampling。
5. [Uncertainty Theory](https://cs109psets.netlify.app/fall22/pset5/)：不确定性与中心极限定理等内容。
6. [Machine Learning](https://cs109psets.netlify.app/fall22/pset6/)：实现机器学习算法，并应用于实际数据集
